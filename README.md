# Portfolio Minimal Premium (Dark-only)

Portfólio pessoal com visual minimalista e navegação simples. O foco é apresentar perfil, experiência e projetos com boa leitura no desktop e no mobile.

## Visão geral
- Layout em duas colunas no desktop (coluna esquerda fixa)
- Transições e microinterações discretas
- Versão mobile com fluxo próprio, sem “quebrar” a experiência

## Stack
- Next.js (App Router)
- TypeScript
- TailwindCSS (tokens via CSS variables)
- Framer Motion
- `next/font` (Google Fonts)

## Requisitos
- Node.js 18+ (20+ recomendado)

## Como rodar
```bash
npm install
npm run dev
